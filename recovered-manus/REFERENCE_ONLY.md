# Recovered Manus tree: reference only

`apps/web` is the sole canonical production application in this repository. The `recovered-manus/` directory is retained only as historical reference material for recovered assets, legacy copy, and migration context.

Do not deploy this directory, add it as a Vercel root directory, or treat its generated HTML/CSS/JavaScript as a competing production implementation. Any future reuse must be reviewed, verified, and migrated deliberately into `apps/web`.
